# 0.2.3 功能与验收契约

生成程序前检查 feature-parity.json 全部条目的覆盖情况，按需读取负责当前改动的源码参考；无需逐文件重复审计。架构、语言、页面步数可以变化，功能及用户可完成的操作须覆盖全部条目。对其他电脑不能照抄当前打包运行时和绝对路径。

二维码是必须实现的可操作入口。电脑先展示扫码图片，并写“使用手机的相机扫描二维码，打开网页链接”；手机页独立展示下载 mitmproxy 证书和后续步骤，桌面保留同步指引。只有地址文本的页面不通过 I02。

baseline-0.2.3 保存本地 0.2.3 功能源码、界面、手机页、测试和授权文件，source-manifest.json 绑定参考字节。desktop 中的原生操作应转换为生成程序内可执行的网页功能，如文件选择、保存备份、日志、返回首页、退出提醒。不能因为未采用 Electron 而省略这些能力。参考代码是设计和算法材料，生成程序须自行提供依赖、入口、服务及网页。

已知验收限制也应继承。原实现曾有完整响应未观测导致按钮无法继续和 Windows GBK 解码错误，当前参考已包含手动确认及 UTF-8 修复；相关回归不得退回旧行为。原先未验证的平台及手机流程不能因复制源码被标成已通过。

## 生成结果验收

生成程序同时输出 acceptance-report.json，每个功能 ID 记录 status（passed/failed/not-tested）、验证方式、证据路径及限制。不得删掉未实现项、将仅有文案或灰显按钮标为 passed，模拟测试与真实手机测试分开标注。failed 的可修复项继续完成，现场不可验证项写明 not-tested。复用同一测试运行的证据可支持多个相关条目，不要求为每个编号单独新增测试。交付时准确说明未验证范围。

必须先跑平台切换、二维码解码与链接、证书下载、任务选择、导出下载、写入及手动确认状态、恢复、退出等自动或本地验证。手机未连接时仍应实现完整页面和后端分支，使用模拟事件验证，不谎称真机成功。

| ID | 功能 | 验收 |
|---|---|---|
| G01 | 单入口与环境 | 双击当前平台入口自动准备运行环境、启动健康服务、打开网页；无开发 PATH 可运行，失败可见且可重试。 |
| G02 | 主操作 | 首页选择 Android/iPhone，导出/替换用两个左右大卡片；连接说明独立展示，恢复通过选择备份 ZIP。 |
| G03 | 导航与任务隔离 | 返回首页确实返回；切换平台、车型、包清空旧成功提示，运行任务先解释中断并妥善停止。 |
| G04 | 备份 | 首次连接提示保存当前模型，用户可选择保存位置；拒绝或取消不伪称已保存，写入恢复备份持久保存。 |
| G05 | 状态真实性 | 分别展示服务、代理、手机、资源请求、外观人工确认；未连接手机不得显示已收到手机连接。 |
| G06 | 授权说明 | 首页简短提示仅供授权学习使用，入口可查看完整授权说明；无未经授权模型分销。 |
| I01 | 局域网准备 | 开始明确电脑手机同一可互访局域网，网线情形可用；无有效局域网地址给修复指引。 |
| I02 | 扫码入口 | 桌面显示真实可扫描二维码，手机相机扫码打开本次手机引导页；地址可复制作为备用，不要求手输长地址。测试实际解码与手机可访问，禁止占位图片、第三方在线生成二维码。 |
| I03 | 手机引导页 | 手机自适应逐步页面，支持上一步、回看；与电脑步骤一致，切到设置后电脑保留当前安装指引。 |
| I04 | 证书下载 | 手机页面实际下载本机 mitmproxy CA，显示证书名称和指纹；证书与代理运行时使用同一 CA，私钥不下发。 |
| I05 | 证书安装 | 独立说明设置→通用→VPN 与设备管理→安装，锁屏密码由用户手机输入；找不到可回下载步骤。 |
| I06 | 完全信任 | 独立说明设置→通用→关于本机→证书信任设置，核对本次 CA；同名旧 CA 不冒充有效。 |
| I07 | 代理设置 | 显示本次真实局域网地址和代理端口，认证关闭、手动、存储；不能硬编码旧 IP，已有上游网络可继续使用。 |
| I08 | 连接检查 | 手机有检查代理连接按钮，桌面展示观测结果；区分 Safari 检查、目标 App 请求、TLS 错误。 |
| I09 | 获取原包 | 从车型资源检查识别实际 filename/md5/url，电脑下载或捕获手机下载，验证完整后可保存 ZIP；已缓存模型无需删 App。 |
| I10 | 车型与版本 | 识别实际车型资源，不能单车型白名单拒绝新车型；无法确认时说明证据缺口，不能猜车型、包平台或选配。 |
| I11 | 载入与更换包 | 支持完整 ZIP 上传、完整性/平台/清单校验，错误明确；代理运行时更换包由网页管理停止与重启及任务隔离，不要求用户手动先停止才选文件。 |
| I12 | 激活引导 | 划掉目标 App，重进爱车模型页建议前台至少15秒；无需寻找不存在的获取按钮，倒计时含义明确。 |
| I13 | 手动外观确认 | 无完整响应但当前任务用户已确认外观时可继续；会话、包、阶段与错误校验有效，证据来源记录人工确认。 |
| I14 | 持久化收尾 | 先激活定制包，再执行官方标识收尾、定制字节返回、再次确认外观；真实 ZIP MD5 与返回标识分别记录。 |
| I15 | 透传验证 | 恢复官方响应并重开确认，检测到官方 ZIP 下载显示风险与重新应用入口，不能误报成功。 |
| I16 | 关闭代理 | 明确引导手机 Wi-Fi→配置代理→关闭→存储，随后停止电脑代理；提前退出告知收尾状态和可能覆盖。 |
| I17 | 直连冷启动 | 正常联网两次冷启动，每次建议15秒，用户在网页确认保留；未保留可重新应用，不能以电脑检测替代视觉结果。 |
| I18 | 断点和范围响应 | 完整返回和 Range、重试、异步确认、旧阶段正在传输的 URL 均返回正确本次字节；旧会话隔离。 |
| A01 | USB 连接 | 区分无设备、未授权、多个设备、断线；显示设备供选择，Windows 驱动指引折叠提供。 |
| A02 | 扫描资源 | 只读识别实际 App 和车型资源目录，用户选择对应车型版本；不会操作其他设备。 |
| A03 | 完整导出 | 导出当前选中车型完整目录，ZIP完整、原始字节哈希核对、可保存到电脑；不添加无关车型档位。 |
| A04 | 写入确认 | 网页选择 ZIP、平台与目标校验，提示将关闭目标 App，取消不写入；备份完成后可在网页授权，无聊天口令。 |
| A05 | 安全写入 | 优先临时目录全量校验后交换，权限受限时采用备份原位写入；全拒绝时写前停止，失败回滚、断线保留恢复事务。 |
| A06 | 传输兼容 | 中文/空格本地路径与全256字节传输正确；Windows 二进制不被文本标准输入修改，MD5逐文件校验。 |
| A07 | 写后结果 | 重新打开手机 App，由用户确认实际外观及重开结果；原样回写全部资源哈希不变。 |
| R01 | 包结构 | 保留完整车型 .ab 与 resources.json、已有清单及关联文件；摘要文件列表完整，导出的原包能重新导入。 |
| R02 | 可选选配 | 遵守 current_configuration 可选协议，已知原始代码才填，哈希绑定所有 .ab/resources.json，iPhone无选配正常导出。 |
| R03 | 安全边界 | 路径穿越、特殊链接、超限/损坏ZIP拒绝；控制端口仅本机且鉴权，手机入口不执行任意本地命令。 |
| R04 | 日志 | 网页“保存日志”可下载，含阶段、会话、传输、失败文件、大小、两侧哈希和恢复结果；UTF-8，敏感信息脱敏。 |
| R05 | 错误恢复 | 依赖、TLS、下载中断、磁盘不足、权限、端口冲突、packing中断均有可行动提示/重试；无无限置灰或静默失败。 |
| R06 | 生命周期 | 重复入口恢复网页，刷新/重开保持本次任务，退出本次进程端口释放；保留备份与证书，误关页面可找回。 |
| R07 | 文案与界面 | 一次一个主步骤，必要状态清楚，无调试字段堆积、冗余恢复选项；等待不宣称下载完成。 每步明确操作设备、起点应用、动作、完成标志与回到哪一页确认；设置代理明确是在 iPhone 上填写，全部步骤按 device-guidance.md 审查。 |

| G07 | 品牌确认与支持范围 | 网页先确认目标品牌，目前仅支持蔚来（NIO）；其他品牌及不确定提示暂未支持，不执行扫描、拦截、导出或写入。可重新选择，切换品牌安全结束旧任务并隔离状态。手机厂商不作为目标App品牌。 |

品牌确认是基于 0.2.3 新增的产品入口要求，与已有功能一并验收。测试选择蔚来可进入平台流程，选择其他品牌显示暂未支持且没有后台任务；正在运行的 iPhone 任务切换品牌须给出关闭手机代理指引。
