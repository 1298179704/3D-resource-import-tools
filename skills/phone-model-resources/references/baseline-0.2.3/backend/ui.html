本机连接

检查电脑与手机连接的 Wi-Fi 名称，操作期间保持电脑开机。

电脑使用网线时，需与手机处在同一个可互访的局域网。

连接遇到问题？

确认电脑和手机连接同一个可互访 Wi-Fi。访客网络可能限制设备互访。电脑保持开机，必要时允许防火墙的局域网连接。

停止助手前，先将手机 Wi-Fi 的「配置代理」设为「关闭」并存储。
