# 每一步都说明操作设备

本文件是生成页面的必读交互要求。适用于电脑页面、手机页面、错误提示和退出指引。不同设备看到的文案分别生成，不能把“此设备”当作手机和电脑共用的指代。

## 步骤构成与检查

每个步骤必须清楚展示操作设备（“在 iPhone 上操作”“在安卓手机上操作”“在电脑上操作”或“在电脑和手机上分别操作”）、起点应用、具体动作、完成标志，以及接下来在哪里点击哪个按钮。设备标签必须常驻步骤标题附近，不能仅在首页说过一次。标签有必要信息价值，禁止以简洁为由省略。

跨设备步骤拆成短段，分别标出设备。不要求每步有长篇说明，通常一行设备标签、一个动作标题、简短路径、完成后的按钮即可。只有路径箭头而无起点设备不通过验收。首次出现的图标配文字，例如“当前 Wi-Fi 名称右侧的 ⓘ 圆圈信息按钮”。填写值直接展示，明确从电脑页面抄到手机哪个字段；复制功能不能冒充跨设备自动粘贴。

用户离开当前页面前，说明会在哪里继续看引导，例如“现在拿起 iPhone 打开设置，电脑保留本页供你对照”。完成动作后说明“回到电脑网页，点击……”。手机网页则写“回到手机浏览器的本页”，不能照抄回到电脑。按钮用完成动作命名，避免无法辨认的“下一步”。

人工确认与自动检测分开表达。设置只凭用户确认时写“我已在 iPhone 上保存代理设置”，不能显示为程序已验证。等待中说明应保持哪个设备、哪个 App、哪个页面。图示辅助定位并注明为示意，系统版本差异导致名称不同时提供折叠帮助。

## iPhone 完整操作对照

| 阶段 | 操作设备与指引 | 完成与回到哪里 |
|---|---|---|
| 确认品牌 | 在电脑网页选择目标 App 品牌，目前仅支持蔚来；其他品牌显示暂未支持 | 选择受支持品牌后才能进入平台选择 |
| 选择操作 | 在电脑网页选择 iPhone，再选择导出或替换；替换时在电脑选择 ZIP | 电脑显示选中包后继续 |
| 同一网络 | 分别在电脑网络设置、iPhone 设置→Wi-Fi 查看已连接网络；有线电脑需与手机可互访 | 回电脑点击“两台设备已连接” |
| 扫二维码 | 在电脑查看二维码，拿起 iPhone，用手机自带相机扫描，点相机出现的网页链接 | iPhone 浏览器打开手机引导页；电脑仍保留说明 |
| 下载证书 | 在 iPhone 浏览器的引导页点“下载 mitmproxy 证书”，出现系统提示点“允许” | 下载后在 iPhone 打开设置，按电脑当前步骤继续；未看到提示有重试入口 |
| 安装证书 | 在 iPhone 打开设置→通用→VPN 与设备管理，找到本次 mitmproxy 描述文件，按提示安装并在手机输入锁屏密码 | 手机显示安装完成，回电脑点“已在 iPhone 安装证书”；不要求在电脑安装证书 |
| 完全信任 | 在 iPhone 设置→通用→关于本机→证书信任设置，核对本次证书并开启完全信任 | 回电脑点“已在 iPhone 开启信任” |
| 设置代理 | 在 iPhone 设置→Wi-Fi，点已连接网络右侧 ⓘ，向下找到配置代理→手动。对照电脑网页，将“服务器”和“端口”填入 iPhone 同名输入框，认证关闭，再点 iPhone 右上角“存储”或“保存” | 回电脑点击“已在 iPhone 保存代理设置”；明确此步骤操作的是 iPhone 当前 Wi-Fi |
| 连接测试 | 在 iPhone 浏览器引导页点“检查连接”，电脑页面查看收到的检测结果 | 失败帮助仍说明在哪个设备检查网络、证书或防火墙 |
| 导出模型 | 在 iPhone 多任务界面划掉车辆 App，再打开车辆 App 进入爱车的 3D 模型页面，前台停留约15秒；电脑显示获取进度 | 在电脑网页点“保存模型到电脑”，保存后显示路径或下载入口 |
| 写入激活 | 在 iPhone 划掉车辆 App 后重开模型页；在手机查看是否出现本次设计 | 外观生效后回电脑点“新外观已显示，继续”，响应未捕获也能人工确认 |
| 收尾与透传 | 按电脑当前步骤在 iPhone 重开车辆 App，停留模型页检查定制外观 | 回电脑确认本阶段外观保留；每次需重开时明确“再次”及目的，避免和上一轮混淆 |
| 关闭代理 | 在 iPhone 设置→Wi-Fi→当前网络右侧 ⓘ→配置代理→关闭，点手机的存储/保存 | 回电脑点“手机代理已关闭，停止电脑代理” |
| 最终验证 | 保持 iPhone 正常联网，在 iPhone 完成两次划掉 App 再进入模型页，每次建议停留15秒 | 确认两次定制外观均保留，回电脑点“两次均已保留，完成” |
| 提前退出 | 电脑告知当前阶段，并给 iPhone 关闭代理的完整路径；备份与任务保留 | 用户确认手机已关代理后，在电脑结束程序 |

## Android 与电脑完整操作对照

| 阶段 | 操作设备与指引 | 完成标志 |
|---|---|---|
| 连接 | 用支持数据传输的数据线把安卓手机接到电脑，手机保持解锁 | 电脑检查连接 |
| USB 调试 | 在安卓手机设置查找开发者选项、开启 USB 调试；厂商路径不同时提供对应折叠说明 | 手机出现调试授权时由用户确认允许这台电脑，电脑检测设备已授权 |
| 无设备 | 在安卓手机确认授权与USB模式，在电脑检查数据线/驱动；分别标出设备 | 点击电脑“重新检查连接” |
| 多设备 | 在电脑网页选择目标手机，展示型号和必要标识 | 后续操作仅绑定该设备 |
| 模型准备 | 在安卓手机打开车辆 App 模型页面让资源准备好，再回电脑点扫描资源 | 电脑显示真实车型目录 |
| 选择资源 | 在电脑网页选车型版本，首次提示保存当前资源备份 | 备份保存到电脑，可见文件位置 |
| 导出 | 在电脑网页点“导出当前手机中的模型”，传输时手机保持连接 | 电脑可下载/保存完整 ZIP |
| 替换 | 在电脑选择 ZIP，说明会关闭安卓手机上的车辆 App，确认备份与写入 | 电脑显示真实传输、校验结果，失败有恢复指引 |
| 效果确认 | 在安卓手机重新打开车辆 App，检查模型外观并重开验证 | 回电脑确认效果；不能把电脑校验成功当成手机外观已验证 |
| 保存日志 | 在电脑网页点“保存日志” | 电脑保存脱敏日志文件，无需用户打开终端 |
| 退出 | 在电脑网页点“退出程序” | 电脑本次后台及端口关闭，备份保留 |

## 逐步验收

覆盖所有正常、返回、错误和退出页面，输出 guidance-audit.json，每项记录步骤ID、页面所在设备、实际操作设备、起点、动作、完成标志、下一确认位置及可观察的页面证据。人工读一遍页面，不允许仅靠字段齐全判断文案清楚。

重点场景必须通过：用户在电脑看到“设置代理”时，能立即知道要拿起 iPhone；用户进入手机设置后无需记忆上一步说明；回网页知道点哪个确认；电脑保存文件和手机输入锁屏密码不会混淆；切换 Android/iPhone 后标签正确。模拟网页可覆盖文案验收，真实小白用户可用性测试未进行时如实标记，不能保证任何人必然完成。
