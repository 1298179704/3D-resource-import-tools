# 本地体验与执行约定

创建完整可独立运行的本地网页引导程序。启动入口自动启动服务并打开网页，所有用户任务、手机操作说明、确认、常见问题和故障恢复都通过网页完成。不要把日常答疑或任务确认设计为必须返回 AI 聊天；遇到未覆盖故障可导出脱敏日志供进一步分析。桌面控制只绑定 127.0.0.1；手机证书下载及连接检测端口按需要绑定当前局域网地址。控制 API 使用随机会话令牌，校验来源、会话及选中包，禁止手机公开入口执行 shell 或读取任意本地路径。生成二维码仅编码本地引导链接，不携带账号信息。证书私钥只留在电脑。

网页一次展示一个明确动作、必要的设置路径、一个主要按钮和返回入口。操作选项与连接说明分开。提示使用手机相机扫描二维码打开网页链接。用户切到手机设置后，电脑仍能查看相同步骤，手机网页也可回看。使用清晰的设置层级和本地生成的示意图，示意图注明系统版本差异，不能伪装为实时截图。

依次展示当前需要的证书下载、安装、完全信任、代理配置步骤。服务器与端口可复制，局域网要求在最开始说明。已经完成的有效证书可复用，先核对当前 CA 指纹，不能只看同名证书。不要关闭用户原有系统代理来维持本工具，必要时串联已有上游代理，避免中断用户或 AI 网络。

状态区使用真实阶段。端口可连接不等于手机已连接，下载响应准备完成不等于手机已激活。超时停止无意义等待，显示可操作恢复项和“保存日志”。用户可手动确认手机结果；完整响应观测不是继续按钮的唯一前提。阶段错误须解释并恢复，不能无声忽略点击。

首次连接提示备份，默认提供易找到的本地保存位置。只提供“导出手机中的模型”“替换手机当前模型”两个操作。恢复备份通过选择备份 ZIP 执行，不猜测用户原厂包。

日志统一 UTF-8 编解码，记录软件版本、阶段变化、传输字节、期望与实际哈希、失败文件和恢复结果。避免记录认证头、完整 URL 查询令牌、VIN 和证书私钥。文件发布前检查无模型、账号或个人证书泄漏。
