# 自动启动与验收

## 生成结果

生成目录包含主入口、网页与本地服务代码、运行时或自动准备机制、局部依赖、运行状态与备份目录。使用任务目录下的相对路径，按系统获取可写应用数据目录。兼容用户目录中文和空格；外部工具传输采用二进制或 ASCII 安全管道。源码参考只能作为材料，完成产品需包含实际可工作的服务 API、网页及生命周期管理。

生成阶段由 AI 准备并测试当前系统所需依赖。不能把 pip、Python、ADB、Node、mitmproxy 安装、环境激活或服务启动命令交给小白用户执行。不假设用户已装 Python、Homebrew、Node 或配置 PATH。支持联网时可自动下载适配系统/架构的官方运行时与依赖，校验来源及发布者提供的校验值，记录版本。准备过程可见且可重试，失败不能一直转圈。若用户要求断网首启，所需依赖必须附带，不能到使用时才下载。

系统可能要求用户信任应用、允许局域网或安装手机证书，应提供准确说明及可恢复入口。不能承诺所有用户环境均无系统提示，不能自动绕过操作系统安全保护。平台不支持或缺少用户权限时准确报告。

## 启动顺序

1. 从入口自身位置解析文件路径，获取可写状态目录，创建互斥锁及本次实例身份。
2. 若已有同应用实例且健康检查、实例令牌匹配，打开其页面；不要启动重复代理或结束陌生进程。
3. 检查局部运行时与依赖，缺失自动准备。将状态与错误写入 UTF-8 日志，启动失败提供用户看得见的错误窗口、重试和日志位置，不能闪退。
4. 自动选择可用控制端口并启动本地服务，健康检查核对版本和实例身份，成功后打开默认浏览器。局域网端口按手机需要另设，端口变化同步更新二维码与说明。
5. 后台退出、浏览器失联或代理失败时，网页显示真实状态并可重连/重启。不能仅检查端口是否监听就报告可用。
6. 重复双击入口可恢复页面。关闭标签后保留可找到的管理入口。网页“退出程序”先完成手机代理关闭确认，再停止本次代理和服务、释放锁与端口。异常退出后下次启动检测残留事务与备份，不能误删其他软件进程。

## 无 AI 对话验收

使用生成后的主入口进行实际检查，不能以开发终端手动启动替代。

- 在移除开发环境 PATH 和 AI 专用环境变量的子进程中启动，局部环境仍可自动就绪。
- 首次缺依赖能自动准备或显示可重试的明确失败；再次启动复用依赖。
- 双击入口自动打开健康网页，重复启动回到原实例；端口被其他进程占用仍能启动。
- 网页独立完成平台选择、导出、选包、写入、用户手动确认、收尾、关闭代理、两次冷启动确认、日志保存。
- 无完整下载响应时，用户明确确认生效仍能推进当前有效会话，错误状态和跨包确认应拒绝。
- 刷新和重开网页能续接，关闭页面后可恢复管理，正式退出释放所有本次进程和端口。
- 缺权限、断网、手机断线、写入校验失败、准备中断有可见错误及恢复操作。
- 默认常见问题在网页可直接阅读，不要求登录 AI、提供 API key 或返回聊天。

只能测试当前机器平台时，注明其他平台未验证。没有手机时可验证启动、网页和模拟协议，但不能声称完成手机安装或持久化实测。


## 平台切换与交付门槛

完成前实际打开网页，逐项验证，发现缺口继续修复。

1. 从首页先确认蔚来品牌，再选择 Android 导出，返回首页，再选择 iPhone 导出。网页必须切换为同 Wi-Fi、证书下载/安装/完全信任、代理设置和资源获取步骤，旧 Android 任务状态不会冒充 iPhone 成功。
2. 用户提出“我现在用 iPhone，怎么用”时，打开或恢复 iPhone 页面，由页面指导手机操作。不能只在聊天发送四步说明和一个证书地址。
3. 从网页选择写入，完成文件校验和必要备份后，通过网页确认即可启动。不能要求回到聊天输入口令。平台或资源身份不匹配须有明确提示与重新选择入口。
4. 没有手机时按钮允许进入相关向导，状态清楚显示待连接；不得以没有真机为理由只实现 Android 页面。实际网络和文件接口用合成任务验证，真实手机结果标记未验证。
5. 中断打包、断开设备、后台重启后，页面能解释中断任务并提供重试或恢复。不能让用户通过再跑无关档位解除 packing 状态。
6. 导出完成下载可用且 ZIP 完整，写入每个确认能推进服务状态。人工检查页面截图或浏览器状态，并测试实际 API，不能仅检查文案存在。

可参考交付回复“本地引导程序已打开。请在首页选择 iPhone，再选择导出或替换模型。下次直接打开 Start 入口即可。”实际地址、入口名和验证限制按本次生成结果填写。用户未要求时不把整套手机操作说明复制回聊天。
