# 手机 AssetBundle 资源 Skill

本仓库现以 `phone-model-resources` Skill 交付。AI 根据用户电脑的系统和架构，生成可直接启动的本地网页引导程序，用户在网页完成模型资源导出、写入、备份和验证。

**当前仅支持蔚来（NIO）App 的适配流程。** 网页先确认目标 App 品牌，其他品牌提示暂未支持。手机厂商与目标 App 品牌分别识别。

## 获取与使用

下载发行版中的 `phone-model-resources-skill.zip`，上传或安装到支持 Skill、本地文件和命令执行的 AI 工具。也可直接读取 [Skill 入口](skills/phone-model-resources/SKILL.md)。

向 AI 发送以下需求。

> 请安装并使用 phone-model-resources Skill，根据我的电脑生成并启动本地网页引导程序。按完整功能与验收要求实现。后续操作在网页完成，每一步明确标注电脑或手机操作，完成后告诉我启动入口。

程序生成后直接打开本地入口使用。入口自动准备环境、启动服务和打开网页。AI 工具需要具备相应本地执行权限。

## 功能与验收

- 网页确认品牌、手机平台及导出或替换任务。
- iPhone 相机扫码、手机证书引导、代理设置、资源获取、手动外观确认、持久化收尾、关闭代理及联网重开验证。
- Android USB 调试、设备选择、车型扫描、原包导出、备份、写入校验及失败恢复。
- 每步标注操作设备，任务切换隔离、错误恢复、日志保存及后台退出管理。
- [39 项功能验收清单](skills/phone-model-resources/references/feature-parity.md)。生成结果逐项标注通过、失败或未测试，模拟验证与真机结果分别记录。

Skill 包含 0.2.3 功能源码和界面参考，供 AI 复用并适配当前电脑。原桌面程序的历史代码可通过 Git 提交历史查看。当前主分支不再交付原桌面应用工程。
